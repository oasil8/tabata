# ⏱️ 타바타 · 나의 운동 시간

> 아이폰 홈 화면에 설치해 쓰는 개인용 타바타 타이머입니다.
> **화면을 꺼도 소리가 이어지고**, 루틴별 메모와 운동 종목 설명을 함께 볼 수 있습니다.

**▶ 바로 쓰기: https://oasil8.github.io/tabata/**

- 순수 HTML·CSS·JavaScript (빌드·npm 의존성 없음), 모든 화면 한국어
- 오프라인에서도 동작하는 PWA
- 앱스토어 배포 없이 사파리에서 바로 설치

---

## 아이폰에 설치하기

1. 사파리에서 위 주소를 엽니다.
2. **공유 → 홈 화면에 추가**를 누릅니다.
3. 처음 한 번은 인터넷이 연결된 상태로 열어 앱 파일과 운동 정보를 받아 둡니다.
4. 홈 화면 앱에서 루틴을 고르고 시작합니다. 자동 재생이 막히면 `재개`를 한 번 더 누르세요.

> 사파리와 홈 화면 앱은 저장 공간이 다를 수 있습니다. 기기를 바꾸거나 데이터를 지우기 전에는 **내보내기**로 백업하세요.

## 주요 기능

| 기능 | 설명 |
|---|---|
| ⏱️ **타이머** | 준비·운동·휴식·라운드·사이클·쿨다운 설정. 상단에 전체 시간과 실시간 남은 시간 표시. |
| 🔊 **화면 꺼져도 소리** | 운동 전체의 음성·비프음을 미리 하나의 오디오로 만들어 재생합니다. 잠금 화면에서 재생·일시정지가 됩니다. |
| 📝 **메모** | 루틴별 종목 순서·주의점(⚠)과 자유 메모. 입력을 멈추면 자동 저장. |
| 💪 **운동 종목 231개** | 맨몸 203 · 케틀벨 17 · 불가리안백 11. 한/영 검색, 부위·장비 필터, 동작 순서·주의점·사진(시작/끝)·유튜브 검색. |
| ➕ **내 종목** | 설명·주의점·영상 링크를 직접 만들어 루틴에 연결. |
| 💾 **백업** | JSON 내보내기(공유 창·파일 저장)와 가져오기(병합 또는 덮어쓰기). |
| 📱 **화면 대응** | 아이폰 세로·가로, 아이패드. safe-area 유지. |

운동 중에는 현재 종목과 직접 적은 주의점, 준비·휴식 때는 다음 종목을 보여 줍니다.
같은 종목이 연달아 오면 `(반대쪽)`을 붙입니다.

## 로컬에서 실행

```sh
python -m http.server 8000     # 저장소 폴더에서
```

**http://localhost:8000** 을 엽니다. `file://`로 열면 서비스워커가 동작하지 않습니다.
아이폰 실기기 확인은 HTTPS인 GitHub Pages 주소로 하세요.

```sh
node --test tests/             # Node.js 22 이상, 설치 없이 테스트
```

## 배포 (GitHub Pages)

`main` 브랜치 루트가 그대로 배포됩니다. **배포할 때마다 `sw.js`의 `CACHE` 버전을 올리세요** (현재 `v22`).

- 새 버전은 운동 중이 아닐 때 자동으로 적용됩니다.
- 같은 파일명의 이미지를 바꿨다면 `IMAGE_CACHE` 버전(현재 `images-v1`)도 올려야 합니다.
- 운동 사진은 설치 후 앱이 열린 뒤 몇 장씩 나눠 받아 둡니다. 설치가 늦어지지 않게 하기 위해서입니다.

## 구조

| 파일 | 역할 |
|---|---|
| `app.js` | 타이머 화면과 재생 |
| `segments.js` | 루틴을 구간(준비·운동·휴식…)으로 펼치기 |
| `audio-render.js`, `audio-cache.js` | 운동 전체 오디오 합성(OfflineAudioContext → WAV)과 캐시 |
| `memo.js`, `exercise-display.js` | 메모 탭, 종목 상세·검색 |
| `store.js` | localStorage 저장(`tabata.local.v1`), 기본 루틴, 백업 검증 |
| `sw.js` | 오프라인 캐시 |
| `data/exercises.json` | 앱이 읽는 운동 DB (`tools/build-exercises.mjs`로 생성) |
| `images/`, `audio/` | 운동 사진, 음성 클립 |

### 화면이 꺼져도 소리가 나는 원리

1. 루틴을 고르거나 저장하면 백그라운드에서 운동 전체의 음성·비프음을 `OfflineAudioContext`로 합성해 WAV 하나로 만듭니다 (20분 이하 16kHz, 그보다 길면 8kHz, 최대 120분).
2. 시작 버튼을 누르는 순간 이 WAV를 `<audio>`로 재생합니다. 아직 만드는 중이면 무음으로 먼저 재생을 열고 완성되면 바꿉니다.
3. 화면에 보이는 시간은 `audio.currentTime`에서 계산하므로, 화면을 다시 켜면 바로 맞춰집니다.
4. 시간 설정이 바뀔 때만 다시 만들고, 이름·종목·메모만 바뀌면 그대로 씁니다.

### 운동 DB 다시 만들기 (앱 실행에는 필요 없음)

```sh
node tools/build-exercises.mjs               # data/exercises.json 생성
node tools/build-exercises.mjs --image-list  # 받아야 할 이미지 목록만 출력
node --test tests/
```

이미지 매핑은 `data/image-map.json`에서 직접 검토합니다. 같은 동작의 wger 사진을 우선하고 free-exercise-db로 보충하며, 비슷한 동작의 참고 사진에는 `approx: true`를 남깁니다.
