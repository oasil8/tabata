# 타바타 · 나의 운동 시간

아이폰 홈 화면에서 사용하는 개인용 타바타 타이머. 순수 HTML/CSS/JavaScript ES 모듈이며 빌드나 npm 의존성이 없습니다. 모든 UI는 한국어입니다. 루틴별 메모, 운동 종목 검색·상세 설명, 내 종목 관리와 운동 중 종목 표시를 지원합니다.

## 로컬 실행과 테스트

저장소 폴더에서 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. `file://`로 열지 마세요. 서비스워커는 HTTPS 또는 localhost에서 동작합니다. 같은 네트워크의 아이폰에서 PC의 HTTP 주소로 접속하면 PWA 기능이 제한되므로 아이폰 검증은 GitHub Pages HTTPS 주소를 사용하세요.

Node.js 22 이상에서 의존성 설치 없이 테스트합니다.

```sh
node --test tests/
```

아이콘 원본: `icons/icon.svg`. PNG(180/192/512)는 이 SVG를 Chrome 헤드리스 스크린샷으로 렌더링해 만듭니다.

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소 루트에 커밋하고 푸시합니다.
2. 저장소 Settings → Pages → Deploy from a branch에서 배포 브랜치와 `/ (root)`를 선택합니다.
3. 표시되는 HTTPS 주소를 엽니다. 하위 저장소 경로에서도 상대경로로 동작합니다.
4. 업데이트할 때 `sw.js`의 캐시 버전(현재 `v13`)을 올립니다. 운동 중 강제 갱신하지 않으므로 열린 앱과 탭을 모두 닫고 다시 열어 새 버전을 적용합니다.

## 아이폰 설치

사파리에서 배포 주소 열기 → 공유 → 홈 화면에 추가. 처음에는 인터넷에 연결한 상태로 열어 앱 파일과 운동 DB를 받아 둡니다. 오프라인 준비 실패 시에만 안내가 표시됩니다. 홈 화면 앱에서 루틴을 선택하고 시작합니다. 처음 오디오 생성이 끝날 때까지 화면을 열어 두세요. 자동 재생이 제한되면 ‘재개’를 한 번 더 누릅니다.

## 화면이 꺼져도 이어지는 오디오

1. 앱 시작·루틴 선택·저장 시 전체 구간의 한국어 음성과 비프음을 OfflineAudioContext로 백그라운드에서 합성하여 하나의 PCM WAV로 준비합니다. 첫 화면을 그린 뒤 requestIdleCallback(미지원 시 setTimeout)으로 시작합니다.
2. 준비된 경우 시작 탭 안에서 곧바로 동일한 audio 요소에 URL을 연결해 재생합니다. 아직 생성 중이면 같은 요소로 무음을 재생해 잠금을 해제하고, 완료 후 WAV로 교체합니다. 대기 문구 없이 시작 버튼과 첫 구간 시간을 유지하며 연속 탭은 무시합니다. 잠금 화면의 미디어 재생·일시정지 동작도 연결합니다.
3. 표시 시간은 audio.currentTime에서만 계산하므로 화면을 다시 켜면 재생 위치에 맞춰 즉시 복원됩니다.

음성 클립(`audio/*.wav`)은 Microsoft Edge 신경망 음성(ko-KR-SunHiNeural, 속도 +30%, 피치 +12Hz, 볼륨 +10%, 문장 끝 느낌표로 힘 있게, `edge-tts`)으로 생성하고 ffmpeg로 앞뒤 무음을 잘라 22.05kHz 모노 WAV로 변환했습니다. 짧은 구간에 다 들어가지 않는 음성은 생략해 다음 구간과 겹치지 않게 합니다. 종료 음성을 끝까지 재생하기 위한 여유 시간은 운동 총 시간에 포함하지 않습니다.

시간 필드(준비·운동·휴식·라운드·사이클·사이클 휴식·쿨다운)를 캐시 키로 사용합니다. 이름·종목·메모만 바뀌면 다시 생성하지 않습니다. 시간 설정이 바뀌면 이전 URL을 해제하며, 생성 중 변경되면 끝난 결과를 폐기한 뒤 최신 설정만 생성합니다. 렌더링은 항상 하나씩 실행하고, 완성된 운동 URL은 최신 하나만 유지합니다. 리셋은 대기 중 자동 시작을 취소하고, 리셋 후 시작과 완료 후 다시 시작은 같은 URL을 currentTime = 0부터 재사용합니다.

20분 이하는 16kHz, 그보다 길면 8kHz 모노를 사용합니다. 40분 기준 Float32 렌더 버퍼 약 77MB + PCM16 약 38MB이며 Blob과 브라우저 디코더 메모리가 추가됩니다. 생성은 최대 120분으로 제한합니다. 기기 메모리 사정에 따라 더 짧은 루틴이 필요할 수 있습니다.

## 루틴과 백업

localStorage의 `tabata.local.v1` 키 하나에 버전, 최초 주입 표시, 선택 ID, 루틴, 내 종목을 저장합니다(`hiddenExerciseIds`는 예전 백업 호환용으로만 남아 있고 사용하지 않습니다). 기본 루틴은 최초 실행 시에만 추가하며 모두 삭제해도 되살리지 않습니다. 저장 스키마의 `version`은 1이며, 배포 전 1단계 데이터 마이그레이션은 하지 않습니다. 기존 형식이나 손상된 데이터는 자동으로 덮어쓰지 않고 읽기 실패를 표시합니다. 저장 실패 시 메모리의 내용은 내보내기로 보관할 수 있습니다.

편집 화면에서 이름과 시간을 수정하거나 새 루틴을 만들고, 카드로 선택·수정·삭제합니다. 시간 편집은 종목과 메모를 유지합니다. 삭제는 앱 내 확인창을 사용합니다. 내보내기는 공유 창(파일에 저장·카톡·에어드롭)으로 JSON 파일을 보내며, 공유를 지원하지 않는 브라우저에서는 다운로드합니다. 가져오기는 버전·필드·범위·중복 ID·HTTPS 영상 주소를 검증한 뒤 병합 또는 덮어쓰기를 선택합니다. 병합은 충돌한 루틴과 내 종목에 새 ID를 부여하고 가져온 루틴의 종목 연결도 바꿉니다. 최대 100개 루틴, 루틴당 200개 종목, 내 종목 500개, 가져오기 파일 64MB까지 지원합니다.

## 메모와 운동 종목

메모 탭에서 루틴을 선택하면 순서 번호·종목 이름·주의점 표시(⚠)가 있는 간결한 목록이 먼저 보입니다. 행을 누르면 해당 루틴 항목의 상세 화면으로 들어가 표시 이름과 주의점(200자)을 수정하고, `‹ 뒤로`로 목록에 돌아옵니다. 목록의 ‘편집’ 토글을 켜면 ▲▼ 순서 변경과 삭제 버튼이 나타납니다. 상세에서도 순서 변경과 삭제가 가능하며 삭제는 앱 내 확인 후 목록으로 돌아옵니다. 자유 메모(2000자)는 종목 목록 아래에 있습니다. 입력을 멈추면 0.4초 후 자동 저장하며, 탭 전환·입력칸 이탈·내보내기 전에도 저장합니다. 검색은 한국어·영어 부분 일치이며 부위/케틀벨/불가리안백 필터와 사용자가 만든 항목만 표시하는 마지막 `내 종목` 칩을 지원합니다. 검색 결과 아래에는 항상 `＋ 내 종목 만들기` 버튼과 안내가 표시되며 검색어가 이름에 미리 채워집니다. 내 종목이 없으면 “아직 만든 종목이 없어요”를 표시합니다. 관리 화면에서도 같은 노란 점선 버튼으로 만듭니다.

항목 상세에서 연결된 종목의 한/영 이름·부위·장비·동작 순서·주의점·이미지와 유튜브 검색 링크를 확인합니다. 연결이 없는 항목은 이름으로 유튜브를 검색하거나 ‘내 종목으로 설명 만들기’로 연결할 수 있습니다. 내 종목 관리에서 설명·주의점·HTTPS 영상 링크를 저장하거나 수정할 수 있습니다. 내 종목을 삭제하면 루틴의 이름과 주의점은 남고 연결만 해제됩니다.

타이머의 ⓘ는 같은 설명을 읽기 전용 시트로 표시하며, 운동 중 시트를 열어도 오디오는 계속됩니다. 로컬 이미지가 2장이면 ‘시작 / 끝’ 라벨과 함께 나란히 표시하고 작은 화면에서는 세로로 배치합니다. 참고 변형에는 ‘비슷한 동작 참고 이미지’, 이미지 아래에는 출처·라이선스와 알려진 저자를 표시합니다. 로드 실패 시 ‘이미지를 불러오지 못했어요’를 표시하며 이미지가 없는 종목에는 이미지 영역을 만들지 않습니다.

낮은 가로 화면에서는 시계가 왼쪽, 종목·라운드·시작 버튼이 오른쪽에 배치됩니다. 아이패드에서는 시계와 조작부를 확대하고, 메모와 편집 다이얼로그는 최대 720px 폭으로 가운데 정렬합니다. 화면 높이는 `100dvh`와 `100vh` 폴백을 사용하며 safe-area를 유지합니다.

운동은 라운드 순서대로 종목을 반복하고 사이클마다 첫 종목부터 시작합니다. 바로 앞 목록 항목과 같은 종목은 ‘(반대쪽)’을 표시하며, 목록 끝에서 처음으로 돌아올 때는 붙이지 않습니다. 준비·휴식에는 다음 종목, 운동에는 현재 종목과 직접 적은 주의점만 표시합니다. 종목이 없는 루틴은 다음 구간과 시간을 표시합니다.

## 데이터 출처와 재생성

운동 정보 일부 출처: [wger.de](https://wger.de/) ([CC-BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)), 한국어 번역·편집. 원본 `data/wger-exercises.en.json`은 수정하지 않으며 원본 ID·영문 설명·이미지 URL·저자 정보를 보존합니다. 앱은 정리된 `data/exercises.json`만 읽습니다. 번역·편집 데이터는 원본과 동일한 CC-BY-SA 4.0 조건으로 제공합니다. 각 항목의 `wgerIds`로 원본 저자를 추적할 수 있고, 직접 작성한 항목은 `source: "app"`으로 구분합니다.

기계·밴드·TRX 등 별도 장비나 비운동 항목을 제외하고 좌우 변형과 중복을 합쳤습니다. 설명은 한국어 동작 순서와 주의점으로 정리했습니다. 이미지 매핑은 `data/image-map.json`에서 직접 검토하며 같은 동작의 wger를 우선하고 free-exercise-db로 보완합니다. 장비·자세 차이가 있는 참고 이미지는 `approx: true`와 검토 근거를 남깁니다. 기존 이미지 보유 종목 62개를 유지해 총 101개로 늘렸으며 기본 루틴 12개 모두 매핑했습니다. 플랭크의 기존 10장은 최대 2장 제한에 맞춰 기존 대표 1장으로 정리했습니다.

이미지 출처는 [wger.de](https://wger.de/)의 CC-BY-SA 4.0 및 [free-exercise-db](https://github.com/yuhonas/free-exercise-db)의 Unlicense 표기입니다. 검토자가 준비한 `data/sources/wger-images.json`, `data/sources/free-exercise-db.json`은 수정하지 않습니다. 매핑은 원본 URL을 보존하고 생성된 운동 JSON의 `imageSource`는 출처·참조 ID·라이선스·참고 여부·알려진 저자를 보존합니다. wger 파생 이미지도 CC-BY-SA 4.0 조건과 저자 표시를 유지해야 합니다. JPG 변환 및 시작/끝 순서의 시각 검토는 다운로드 담당 검토자가 수행합니다. 기존 좌우 이미지 묶음 등 순서 확인이 필요한 항목은 매핑의 `note`를 확인하세요.

앱은 `images/<종목id>-1.jpg`, `images/<종목id>-2.jpg`를 지연 로딩합니다. 서비스워커는 앱 파일을 `…-v20`, 이미지를 범위별 고정 캐시 `…-images-v1`에 분리합니다. 설치 시 새 운동 JSON을 읽어 이미지 캐시에 없는 파일만 저장하며 활성화 시 이미지 캐시는 유지합니다. 이미지 요청은 캐시 우선이고 누락분은 온라인 요청 시 저장합니다. 실패·404는 캐시하지 않으며 이미지 실패로 앱 설치를 막지 않습니다. 한 번 저장된 이미지는 오프라인에서도 표시됩니다. 같은 경로의 이미지를 교체할 때는 고정 캐시 버전도 올려야 교체본을 받습니다.

현재 총 231개(맨몸 203개·케틀벨 17개·불가리안백 11개)이며, 이 중 앱 자체 항목은 18개입니다. 불가리안백은 스핀, 암 스로, 벤트 프레스, 스윙(어깨 위로), 스쿼트, 런지, 스내치, 클린 & 프레스, 파워 스내치, 굿모닝, 로테이셔널 런지를 포함합니다. 원본 298개 중 248개 ID를 포함·병합했고, 50개는 빌더에 사유를 남겨 제외했습니다.

재생성(앱 실행에는 필요 없음):

```sh
node tools/build-exercises.mjs
node tools/build-exercises.mjs --image-list
node --test tests/
```

빌더의 분류·번역 또는 이미지 매핑을 수정한 뒤 재생성하고, DB 무결성 및 시드 참조 테스트를 확인하세요. `--image-list`는 파일을 변경하지 않고 `원격URL<TAB>로컬경로`만 출력합니다. 검토자는 이 목록으로 이미지를 별도 다운로드·JPG 변환하고 지정된 `images/` 경로에 배치한 뒤 배포합니다. 빌더는 네트워크 요청이나 이미지 변환을 하지 않습니다. 테스트는 매핑 키·URL·필수 12개·빌드 재현성과 별도 이미지 캐시의 유지·누락분 저장·실패 처리를 확인합니다. 실제 사진 파일과 시작/끝 자세의 시각 확인은 별도 절차입니다.

사파리와 설치한 홈 화면 앱의 저장 공간이 다를 수 있으므로 각 실행 환경에서 백업을 확인하세요. 브라우저 데이터 삭제나 기기 변경 전에는 내보내기가 필요합니다.

## 확인할 동작

- 6단계: 루틴 편집·종목 상세·내 종목 만들기/수정 창은 safe-area를 포함한 하단 탭바 위에서 스크롤됩니다. 창 뒤 본문은 비활성화되며, 작은 확인 창은 기존 모달을 유지합니다.
- 하단 탭은 같은 탭을 다시 눌러도 열린 창을 닫고 해당 메인 화면 맨 위로 돌아갑니다. 미저장 편집은 취소하고 자동 저장 메모는 먼저 반영하며, 탭 이동 자체는 운동 재생에 영향을 주지 않습니다. 메모 탭은 항상 루틴 목록으로 돌아갑니다.
