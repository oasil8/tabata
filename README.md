# 타바타 · 나의 운동 시간

아이폰 홈 화면에서 사용하는 개인용 타바타 타이머. 순수 HTML/CSS/JavaScript ES 모듈이며 빌드나 npm 의존성이 없습니다. 모든 UI는 한국어입니다. 메모 탭은 준비 중이며 운동 종목 DB는 사용하지 않습니다.

## 로컬 실행과 테스트

저장소 폴더에서 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. `file://`로 열지 마세요. 서비스워커는 HTTPS 또는 localhost에서 동작합니다. 같은 네트워크의 아이폰에서 PC의 HTTP 주소로 접속하면 PWA 기능이 제한되므로 아이폰 검증은 GitHub Pages HTTPS 주소를 사용하세요.

Node.js 22 이상에서 의존성 설치 없이 테스트합니다.

```sh
node --test tests/
```

아이콘 재생성: `node icons/generate.mjs` (Node 내장 zlib만 사용).

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소 루트에 커밋하고 푸시합니다.
2. 저장소 Settings → Pages → Deploy from a branch에서 배포 브랜치와 `/ (root)`를 선택합니다.
3. 표시되는 HTTPS 주소를 엽니다. 하위 저장소 경로에서도 상대경로로 동작합니다.
4. 업데이트할 때 `sw.js`의 캐시 버전 `v1`을 올립니다. 운동 중 강제 갱신하지 않으므로 열린 앱과 탭을 모두 닫고 다시 열어 새 버전을 적용합니다.

## 아이폰 설치

사파리에서 배포 주소 열기 → 공유 → 홈 화면에 추가. 처음에는 인터넷에 연결한 상태로 열고 ‘오프라인 준비가 완료되었습니다’를 확인하세요. 홈 화면 앱에서 루틴을 선택하고 시작합니다. 처음 오디오 생성이 끝날 때까지 화면을 열어 두세요. 자동 재생이 제한되면 ‘재개’를 한 번 더 누릅니다.

## 화면이 꺼져도 이어지는 오디오

1. 전체 구간의 한국어 음성과 비프음을 OfflineAudioContext로 미리 합성하여 하나의 PCM WAV로 만듭니다.
2. 탭 순간 동일한 audio 요소에서 무음을 재생한 후 WAV로 교체하고, 잠금 화면의 미디어 재생·일시정지 동작을 연결합니다.
3. 표시 시간은 audio.currentTime에서만 계산하므로 화면을 다시 켜면 재생 위치에 맞춰 즉시 복원됩니다.

음성 클립(`audio/*.wav`)은 Windows TTS로 생성한 한국어 음성입니다. 짧은 구간에 다 들어가지 않는 음성은 생략해 다음 구간과 겹치지 않게 합니다. 종료 음성을 끝까지 재생하기 위한 여유 시간은 운동 총 시간에 포함하지 않습니다.

20분 이하는 16kHz, 그보다 길면 8kHz 모노를 사용합니다. 40분 기준 Float32 렌더 버퍼 약 77MB + PCM16 약 38MB이며 Blob과 브라우저 디코더 메모리가 추가됩니다. 생성은 최대 120분으로 제한합니다. 기기 메모리 사정에 따라 더 짧은 루틴이 필요할 수 있습니다. 생성 중 리셋은 결과를 폐기하지만 이미 시작한 브라우저 렌더링이 끝나기 전에는 새 렌더링을 시작하지 않습니다.

## 루틴과 백업

localStorage의 `tabata.local.v1` 키 하나에 버전, 최초 주입 표시, 선택 ID, 루틴 목록을 JSON으로 저장합니다. 기본 루틴은 최초 실행 시에만 추가하며 모두 삭제해도 되살리지 않습니다. 각 루틴은 2단계용 빈 `exercises` 배열을 포함합니다. 저장 실패는 화면에 표시하며 메모리의 루틴은 내보내기로 보관할 수 있습니다.

편집 화면에서 이름과 시간을 수정하거나 새 루틴을 만들고, 카드로 선택·수정·삭제합니다. 삭제는 앱 내 확인창을 사용합니다. 내보내기는 JSON 파일을 다운로드합니다. 가져오기는 버전·필드·범위·중복 ID를 검증한 뒤 병합 또는 덮어쓰기를 선택합니다. 병합은 ID 충돌 항목도 새 ID로 보존합니다. 최대 100개 루틴, 백업 파일 1MB까지 지원합니다.

사파리와 설치한 홈 화면 앱의 저장 공간이 다를 수 있으므로 각 실행 환경에서 백업을 확인하세요. 브라우저 데이터 삭제나 기기 변경 전에는 내보내기가 필요합니다.

## 확인할 동작

- 기본 총 시간: 매일 복근 4:01, KB전신운동 19:37. 각 사이클의 마지막 라운드 뒤 휴식을 생략합니다.
- 시작 → 준비 음성 → 운동 전환, 일시정지·재개·리셋, 짧은 루틴의 종료 음성.
- 실제 아이폰에서 화면 잠금 후 소리 지속, 잠금 화면 재생 제어, 복귀 시 표시 동기화.
- 한 번 캐시한 뒤 네트워크를 끊고 앱 다시 열기 및 운동 시작.
- 루틴 저장·삭제 후 재실행, JSON 내보내기·병합·덮어쓰기와 잘못된 파일 거부.

실제 아이폰 잠금 재생과 전화·다른 앱의 오디오 간섭은 기기에서 별도로 확인해야 합니다. Wake Lock은 지원되는 환경에서만 요청하고 실패해도 운동은 계속됩니다.
