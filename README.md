# 타바타 · 나의 운동 시간

아이폰 홈 화면에서 사용하는 개인용 타바타 타이머. 순수 HTML/CSS/JavaScript ES 모듈이며 빌드나 npm 의존성이 없습니다. 모든 UI는 한국어입니다. 루틴별 메모, 운동 종목 검색·상세 설명, 내 종목 관리와 운동 중 종목 표시를 지원합니다.

## 로컬 실행과 테스트

저장소 폴더에서 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. `file://`로 열지 마세요. 서비스워커는 HTTPS 또는 localhost에서 동작합니다. 같은 네트워크의 아이폰에서 PC의 HTTP 주소로 접속하면 PWA 기능이 제한되므로 아이폰 검증은 GitHub Pages HTTPS 주소를 사용하세요.

Node.js 22 이상에서 의존성 설치 없이 테스트합니다.

```sh
node --test tests/
```

아이콘 재생성: `node icons/generate.mjs` (Node 내장 zlib만 사용).

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소 루트에 커밋하고 푸시합니다.
2. 저장소 Settings → Pages → Deploy from a branch에서 배포 브랜치와 `/ (root)`를 선택합니다.
3. 표시되는 HTTPS 주소를 엽니다. 하위 저장소 경로에서도 상대경로로 동작합니다.
4. 업데이트할 때 `sw.js`의 캐시 버전(현재 `v2`)을 올립니다. 운동 중 강제 갱신하지 않으므로 열린 앱과 탭을 모두 닫고 다시 열어 새 버전을 적용합니다.

## 아이폰 설치

사파리에서 배포 주소 열기 → 공유 → 홈 화면에 추가. 처음에는 인터넷에 연결한 상태로 열어 앱 파일과 운동 DB를 받아 둡니다. 오프라인 준비 실패 시에만 안내가 표시됩니다. 홈 화면 앱에서 루틴을 선택하고 시작합니다. 처음 오디오 생성이 끝날 때까지 화면을 열어 두세요. 자동 재생이 제한되면 ‘재개’를 한 번 더 누릅니다.

## 화면이 꺼져도 이어지는 오디오

1. 전체 구간의 한국어 음성과 비프음을 OfflineAudioContext로 미리 합성하여 하나의 PCM WAV로 만듭니다.
2. 탭 순간 동일한 audio 요소에서 무음을 재생한 후 WAV로 교체하고, 잠금 화면의 미디어 재생·일시정지 동작을 연결합니다.
3. 표시 시간은 audio.currentTime에서만 계산하므로 화면을 다시 켜면 재생 위치에 맞춰 즉시 복원됩니다.

음성 클립(`audio/*.wav`)은 Windows TTS로 생성한 한국어 음성입니다. 짧은 구간에 다 들어가지 않는 음성은 생략해 다음 구간과 겹치지 않게 합니다. 종료 음성을 끝까지 재생하기 위한 여유 시간은 운동 총 시간에 포함하지 않습니다.

20분 이하는 16kHz, 그보다 길면 8kHz 모노를 사용합니다. 40분 기준 Float32 렌더 버퍼 약 77MB + PCM16 약 38MB이며 Blob과 브라우저 디코더 메모리가 추가됩니다. 생성은 최대 120분으로 제한합니다. 기기 메모리 사정에 따라 더 짧은 루틴이 필요할 수 있습니다. 생성 중 리셋은 결과를 폐기하지만 이미 시작한 브라우저 렌더링이 끝나기 전에는 새 렌더링을 시작하지 않습니다.

## 루틴과 백업

localStorage의 `tabata.local.v1` 키 하나에 버전, 최초 주입 표시, 선택 ID, 루틴, 내 종목과 숨긴 DB 종목 ID를 저장합니다. 기본 루틴은 최초 실행 시에만 추가하며 모두 삭제해도 되살리지 않습니다. 저장 스키마의 `version`은 1이며, 배포 전 1단계 데이터 마이그레이션은 하지 않습니다. 기존 형식이나 손상된 데이터는 자동으로 덮어쓰지 않고 읽기 실패를 표시합니다. 저장 실패 시 메모리의 내용은 내보내기로 보관할 수 있습니다.

편집 화면에서 이름과 시간을 수정하거나 새 루틴을 만들고, 카드로 선택·수정·삭제합니다. 시간 편집은 종목과 메모를 유지합니다. 삭제는 앱 내 확인창을 사용합니다. 내보내기는 JSON 파일을 다운로드합니다. 가져오기는 버전·필드·범위·중복 ID·HTTPS 영상 주소를 검증한 뒤 병합 또는 덮어쓰기를 선택합니다. 병합은 충돌한 루틴과 내 종목에 새 ID를 부여하고 가져온 루틴의 종목 연결도 바꿉니다. 숨긴 종목은 합집합으로 병합합니다. 최대 100개 루틴, 루틴당 200개 종목, 내 종목 500개, 가져오기 파일 64MB까지 지원합니다.

## 메모와 운동 종목

메모 탭에서 루틴을 선택하면 자유 메모(2000자)와 종목별 주의점(200자)을 입력할 수 있습니다. 입력을 멈추면 0.4초 후 자동 저장하며, 탭 전환·입력칸 이탈·내보내기 전에도 저장합니다. 표시 이름 수정, ▲▼ 순서 변경, 종목 삭제를 지원합니다. 검색은 한국어·영어 부분 일치이며 부위/케틀벨 필터를 적용할 수 있습니다. 숨긴 DB 종목은 검색에서 빠지지만 기존 루틴 연결은 유지됩니다.

ⓘ 상세에서 동작 순서·주의점·이미지와 유튜브 검색 링크를 확인합니다. 운동 중 시트를 열어도 오디오는 계속됩니다. 내 종목 관리에서 설명·주의점·HTTPS 영상 링크를 저장하거나 수정할 수 있습니다. 내 종목을 삭제하면 루틴의 이름과 주의점은 남고 연결만 해제됩니다.

운동은 라운드 순서대로 종목을 반복하고 사이클마다 첫 종목부터 시작합니다. 바로 앞 목록 항목과 같은 종목은 ‘(반대쪽)’을 표시하며, 목록 끝에서 처음으로 돌아올 때는 붙이지 않습니다. 준비·휴식에는 다음 종목, 운동에는 현재 종목과 직접 적은 주의점만 표시합니다. 종목이 없는 루틴은 다음 구간과 시간을 표시합니다.

## 데이터 출처와 재생성

운동 정보 일부 출처: [wger.de](https://wger.de/) ([CC-BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)), 한국어 번역·편집. 원본 `data/wger-exercises.en.json`은 수정하지 않으며 원본 ID·영문 설명·이미지 URL·저자 정보를 보존합니다. 앱은 정리된 `data/exercises.json`만 읽습니다. 번역·편집 데이터는 원본과 동일한 CC-BY-SA 4.0 조건으로 제공합니다. 각 항목의 `wgerIds`로 원본 저자를 추적할 수 있고, 직접 작성한 항목은 `source: "app"`으로 구분합니다.

기계·밴드·TRX 등 별도 장비나 비운동 항목을 제외하고 좌우 변형과 중복을 합쳤습니다. 설명은 한국어 동작 순서와 주의점으로 정리했습니다. 이미지 URL은 wger 원격 주소이며 지연 로딩하고 실패하면 숨깁니다. 이미지는 서비스워커에 캐시하지 않으므로 오프라인에서는 보이지 않을 수 있습니다. 운동 JSON과 앱 모듈은 서비스워커 캐시에 포함됩니다.

현재 총 220개(맨몸 203개·케틀벨 17개)이며, 이 중 앱 자체 항목은 7개입니다. 원본 298개 중 248개 ID를 포함·병합했고, 50개는 빌더에 사유를 남겨 제외했습니다.

재생성(앱 실행에는 필요 없음):

```sh
node tools/build-exercises.mjs
node --test tests/
```

빌더의 분류·번역 내용을 수정한 뒤 재생성하고, DB 무결성 및 시드 참조 테스트를 확인하세요.

사파리와 설치한 홈 화면 앱의 저장 공간이 다를 수 있으므로 각 실행 환경에서 백업을 확인하세요. 브라우저 데이터 삭제나 기기 변경 전에는 내보내기가 필요합니다.

## 확인할 동작

- 기본 총 시간: 매일 복근 4:01, KB전신운동 19:37. 각 사이클의 마지막 라운드 뒤 휴식을 생략합니다.
- 시작 → 준비 음성 → 운동 전환, 일시정지·재개·리셋, 짧은 루틴의 종료 음성.
- 실제 아이폰에서 화면 잠금 후 소리 지속, 잠금 화면 재생 제어, 복귀 시 표시 동기화.
- 한 번 캐시한 뒤 네트워크를 끊고 앱 다시 열기 및 운동 시작.
- 루틴 저장·삭제 후 재실행, JSON 내보내기·병합·덮어쓰기와 잘못된 파일 거부.

실제 아이폰 잠금 재생과 전화·다른 앱의 오디오 간섭은 기기에서 별도로 확인해야 합니다. Wake Lock은 지원되는 환경에서만 요청하고 실패해도 운동은 계속됩니다.
